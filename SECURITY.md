# Security

Gym Ledger is a personal app. It stores all data on the phone and never uses the internet.

## Report a problem

Found a security problem? Report it in private:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.

Please do not open a public issue for a security problem. I answer when I can; this is a one-person project.

## Supported version

Only the newest commit on `main` gets fixes.
